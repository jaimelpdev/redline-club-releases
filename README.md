# REDLINE CLUB · descargas

Instaladores de la app de escritorio de REDLINE CLUB para Windows: academia de simracing con ingeniero por radio, telemetría real y programa de 12 meses.

**[Descargar la última versión](https://github.com/jaimelpdev/redline-club-releases/releases/latest)** (`REDLINE-CLUB-Setup-<versión>.exe`).

- Se instala para tu usuario, sin permisos de administrador.
- La app avisa sola cuando hay versión nueva y la instala comprobando su huella (SHA-256) antes de ejecutarla.
- Tus datos se quedan en tu PC (`%APPDATA%\REDLINE CLUB`), con copia de seguridad diaria.

Si Windows muestra "Windows protegió su PC", pulsa **Más información → Ejecutar de todas formas**: el instalador aún no lleva firma de código.

Aquí solo se publican los instaladores; el código no es público.
